## 3. CPU vs CUDA 비교

### 학습 시간

| 모델 조합 | CPU | CUDA | 속도 향상 |
|----------|-----|------|---------|
| filters=8, layers=1, BN 없음 | 2.87s | 2.28s | 1.3x |
| filters=32, layers=3, BN 없음 | 14.76s | 11.22s | 1.3x |
| filters=64, layers=3, BN 없음 | 34.50s | 23.61s | 1.5x |
| filters=128, layers=3, BN 없음 | 93.85s | 46.44s | 2.0x |
| filters=128, layers=6, BN 있음 | 122.03s | 67.12s | 1.8x |

### 추론 시간

| 모델 조합 | CPU | CUDA | 속도 향상 |
|----------|-----|------|---------|
| filters=8, layers=1, BN 없음 | 0.167s | 0.124s | 1.4x |
| filters=32, layers=3, BN 없음 | 1.059s | 0.518s | 2.0x |
| filters=128, layers=3, BN 없음 | 6.665s | 2.658s | 2.5x |
| filters=128, layers=6, BN 있음 | 7.61s | 3.55s | 2.1x |

**관찰:** 모델이 클수록 CUDA 가속 효과가 커진다. 작은 모델(filters=8)에서는 GPU 오버헤드 때문에 이점이 적다.

---

## 4. num_filters가 실행 시간에 미치는 영향

conv_layers=1, BN 없음 기준 (CPU 학습 시간):

| num_filters | 학습 시간 (CPU) | 추론 시간 (CPU) |
|-------------|--------------|--------------|
| 8 | 2.87s | 0.167s |
| 16 | 4.69s | 0.291s |
| 32 | 9.40s | 0.666s |
| 64 | 18.24s | 1.405s |
| 128 | 35.65s | 3.085s |

**관찰:** filters가 2배 증가할 때 실행 시간도 약 2배 증가한다. 필터 수는 FLOPs에 직접 비례하므로 예상된 결과다.

---

## 5. num_conv_layers가 실행 시간에 미치는 영향

filters=32, BN 없음 기준 (CPU):

| num_conv_layers | 학습 시간 (CPU) | 추론 시간 (CPU) |
|----------------|--------------|--------------|
| 1 | 9.40s | 0.666s |
| 2 | 12.98s | 0.924s |
| 3 | 14.76s | 1.059s |
| 4 | 15.74s | 1.124s |
| 5 | 16.37s | 1.150s |
| 6 | 17.12s | 1.158s |

**관찰:** 레이어 수가 늘어도 실행 시간 증가폭이 줄어든다. MaxPool이 매 레이어마다 특성 맵 크기를 절반으로 줄이기 때문에, 깊어질수록 각 레이어의 연산량이 작아진다.

---

## 6. BatchNorm이 실행 시간에 미치는 영향

filters=32, conv_layers=3 기준 (CPU):

| BatchNorm | 학습 시간 | 추론 시간 |
|-----------|---------|---------|
| 없음 | 14.76s | 1.059s |
| 있음 | 19.35s | 1.121s |
| 증가율 | **+31%** | **+6%** |

**관찰:** BatchNorm은 학습 시간에 더 큰 영향을 준다. 학습 시에는 배치 통계 계산 및 역전파 비용이 추가되지만, 추론 시에는 통계가 고정되어 영향이 작다.

---

## 7. 측정 안정성 (표준편차)

대부분의 조합에서 표준편차가 평균의 5% 이하로 안정적이다.
단, 아래 케이스에서 이상값이 관찰되었다:

| 조합 | 장치 | 학습 시간 std |
|------|------|-------------|
| filters=128, layers=5, BN 있음 | CUDA | 12.98s (평균 54.72s의 24%) |

이는 CUDA 실행 중 간헐적인 스케줄링 지연으로 추정된다. 해당 데이터는 예측 모델 학습 시 outlier로 작용할 수 있다.
