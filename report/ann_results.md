## 3. CPU vs CUDA 비교

### 학습 시간

| 모델 조합 | CPU | CUDA | 비고 |
|----------|-----|------|------|
| hidden=16, layers=1 | 0.856s | 1.310s | CPU가 1.5x 빠름 |
| hidden=128, layers=1 | 1.039s | 1.322s | CPU가 1.3x 빠름 |
| hidden=512, layers=1 | 2.145s | 1.889s | CUDA가 1.1x 빠름 |
| hidden=512, layers=7 | 10.010s | 9.083s | CUDA가 1.1x 빠름 |
| hidden=1024, layers=4 | 18.184s | 16.742s | CUDA가 1.1x 빠름 |
| hidden=1024, layers=7 | 34.523s | 30.119s | CUDA가 1.1x 빠름 |

**관찰:** CNN과 달리 ANN에서는 작은 모델일수록 CPU가 더 빠르다. CUDA 가속 효과가 최대 1.1배 수준으로 CNN(최대 2.5배)보다 훨씬 적다.

**이유:** ANN은 순차적인 Linear 레이어 연산이 주를 이루며, GPU로 데이터를 전송하는 오버헤드가 연산 이득을 상쇄한다. 특히 MNIST(784차원) 같은 작은 입력에서는 GPU의 대규모 병렬 처리 이점이 거의 없다.

### 추론 시간

| 모델 조합 | CPU | CUDA | 비고 |
|----------|-----|------|------|
| hidden=16, layers=1 | 0.013s | 0.028s | CPU가 2.2x 빠름 |
| hidden=128, layers=1 | 0.021s | 0.032s | CPU가 1.5x 빠름 |
| hidden=512, layers=7 | 0.234s | 0.180s | CUDA가 1.3x 빠름 |
| hidden=1024, layers=7 | 0.744s | 0.433s | CUDA가 1.7x 빠름 |

**관찰:** 추론 시간에서도 작은 모델은 CPU가 빠르고, 큰 모델에서만 CUDA 이점이 나타난다.

## 4. hidden_size가 실행 시간에 미치는 영향

num_hidden_layers=1 기준 (CPU):

| hidden_size | 학습 시간 (CPU) | 추론 시간 (CPU) |
|-------------|--------------|--------------|
| 16 | 0.856s | 0.013s |
| 32 | 0.895s | 0.014s |
| 64 | 0.933s | 0.016s |
| 128 | 1.039s | 0.021s |
| 256 | 1.219s | 0.030s |
| 512 | 2.145s | 0.054s |
| 1024 | 3.607s | 0.086s |

**관찰:** hidden_size=512부터 실행 시간이 급격히 증가한다. 16~256 구간에서는 완만하게 증가하다가, 512 이상에서는 파라미터 수가 크게 늘어나며 시간이 빠르게 증가한다.

---

## 5. num_hidden_layers가 실행 시간에 미치는 영향

hidden_size=512 기준 (CPU):

| num_hidden_layers | 학습 시간 (CPU) | 추론 시간 (CPU) |
|------------------|--------------|--------------|
| 1 | 2.145s | 0.054s |
| 2 | 3.575s | 0.080s |
| 3 | 4.814s | 0.113s |
| 4 | 6.076s | 0.137s |
| 5 | 7.254s | 0.176s |
| 6 | 8.722s | 0.207s |
| 7 | 10.010s | 0.234s |

**관찰:** 레이어 수가 1개 늘 때마다 약 1.2~1.3s씩 선형적으로 증가한다. CNN과 달리 ANN은 레이어가 깊어져도 연산량이 일정하게 증가한다 (MaxPool 같은 크기 축소가 없기 때문).

---

## 6. 측정 안정성 (표준편차)

| 장치 | 표준편차 특성 |
|------|------------|
| CPU | 평균의 1~5% 수준, 전반적으로 안정적 |
| CUDA | 대부분 0.001s 미만으로 매우 안정적 |

CUDA에서 ANN 측정이 CNN보다 훨씬 안정적인 이유는 ANN 연산이 단순하고 결정론적이기 때문이다.

---

## 7. CNN과 비교

| 항목 | ANN | CNN |
|------|-----|-----|
| CUDA 가속 효과 | 최대 1.7x (대부분 미미) | 최대 2.5x |
| 소형 모델 CUDA | CPU보다 느림 | CPU보다 약간 빠름 |
| 레이어 수 증가 영향 | 선형적 증가 | 증가폭 감소 (MaxPool) |
| 측정 안정성 | 보통 | CUDA에서 간헐적 이상값 |
