# GPU 3대 정밀 분석 — 세 가지 체제(오버헤드·메모리·연산)와 사양 전이 (2026-09-26)

76번(LOGO)의 후속. 76의 결론은 "트리는 TFLOPS를 안 쓰고 외삽을 못 한다, 학습시간은 log-TFLOPS 보간이 낫다"였다. 여기서는 그 이유를 세 GPU의 **같은 구성끼리 직접 비교**해서 파고, 사양만으로 다른 GPU에 전이되는 작은 물리 모델을 시험한다.
데이터: 세 GPU 공통 54구성(ANN 10·CNN 8·ResNet 10·MobileNet 10·ViT 8·GAN 8). **4060 Ti는 v2 재측정(9월, 1050·3060과 같은 프로토콜)** 을 썼다. 스크립트는 문서 안 코드와 동일, 수치 `paper/roofline_transfer.json`.

## 0. 먼저 걷어낸 교란 — 4060 Ti v1(3월) vs v2(9월)

같은 54구성에서 4060 Ti v2/v1 = 학습 1.12×(소형 1.20×), 추론 1.00×(소형 1.27×). 75번 문서의 "3060은 4060 Ti보다 26% 느림(예측÷실측 0.74)"은 v1 기준이었고, v2로 맞추면 3060/4060 Ti 학습 비는 중앙 **1.10×**, "4060 Ti 복사" 오차는 24.8% → **16.7%**로 줄어든다. 즉 75·76의 격차 일부는 데스크톱 드리프트였다. 이하 전부 v2 기준.

## 1. 공개 사양이 가리키는 방향이 서로 다르다

| | TFLOPS | 메모리 대역폭 (GB/s) | 호스트 CPU |
|---|---:|---:|---|
| GTX 1050 | 2.51 | 112 | i3-8100 (3.6 GHz) |
| RTX 3060 | 15.48 | **360** | i7-10700F (부스트 4.8) |
| RTX 4060 Ti | 26.98 | 288 | 7800X3D (부스트 5.0) |

3060은 4060 Ti보다 TFLOPS는 43% 낮지만 **대역폭은 25% 높다**. 그래서 "3060이 4060 Ti보다 빠른 구성"이 있다면 그건 메모리가 병목인 구성이어야 한다 — Roofline의 직접 시험이 된다.

(대역폭은 수집기가 못 채운 값이라 NVIDIA 공개 스펙을 썼다.)

## 2. 결과 — 세 체제가 실측에 그대로 보인다

**(a) ResNet이 산술 강도로 깔끔하게 둘로 갈린다.** 산술 강도 = FLOPs ÷ (메모리 읽기+쓰기), ONNX 정적 프록시.

| ResNet 구성 | 산술 강도 | 3060/4060 Ti | 1050/4060 Ti |
|---|---:|---:|---:|
| w16 네 개 | 11~14 | **0.95~1.01** | **2.5~3.0** |
| w32 두 개 | 15~17 | 1.52~1.53 | 6.1~6.2 |
| w64 네 개 | 17~23 | 1.64~1.65 | 6.6~8.1 |
| (참고) 대역폭 비 / TFLOPS 비 | | 0.80 / 1.74 | 2.57 / 10.75 |

폭 16짜리는 **대역폭 비를 따르고**(3060이 오히려 빠르거나 같음, 1050은 2.57배 근처) 폭 32·64는 **TFLOPS 비를 따른다**(1.74·10.75 쪽). 경계는 산술 강도 약 15. 학습시간에서 3060이 4060 Ti보다 빠른 세 구성이 모두 ResNet w16이다.

**(b) 가장 작은 모델은 GPU가 아니라 호스트 CPU를 따른다.** ANN 한 배치 학습시간: 1050(i3) 1.13 ms · 3060(i7) 0.63 ms · 4060 Ti(7800X3D) 0.55 ms. ANN_h16과 h64가 거의 같다(연산량이 4배 달라도). 1050이 2배 느린 건 GPU가 아니라 i3 때문이다 — 커널을 던지는 파이썬·드라이버 오버헤드가 싱글 스레드 성능에 묶인다.

**(c) 크기별로 정리하면** (학습, 비 중앙값): 소형 3060 1.08 · 1050 2.01 / 대형 3060 1.52 · 1050 6.09. 소형은 호스트 비(1.15·2.05)에, 대형은 TFLOPS 쪽에 붙는다.

## 3. 사양 전이 — 4개 파라미터 물리 모델

한 GPU(원본)의 "4060 Ti 대비 감속 비"로 아래 식의 파라미터 4개를 맞추고, **다른 GPU의 공개 사양만 넣어** 그 GPU를 예측한다.

log(감속비) = o·log(호스트비) + (1−o)·[ w·log(TFLOPS비) + (1−w)·log(대역폭비) ]
o = σ(a₀ + a₁·log 기준시간) (작을수록 오버헤드 비중 ↑), w = σ(b₀ + b₁·log 산술강도) (강도 높을수록 연산 비중 ↑)

예측 = 4060 Ti 실측 × 감속비. 즉 **새 GPU는 한 번도 안 재고**, 기준 GPU에서 그 구성을 잰 값과 사양만 쓴다.

| 학습시간 MAPE / MdAPE | 1050에 맞춤 → 3060 예측 | 3060에 맞춤 → 1050 예측 |
|---|---:|---:|
| **물리 모델 (호스트비 = 공개 부스트 클럭비, 대상 측정 0)** | **11.8 / 8.7** | **30.8 / 27.7** |
| 물리 모델 (호스트비 = 대상에서 가장 작은 구성 1개로 보정) | 11.8 / 9.0 | 29.5 / 17.2 |
| 4060 Ti 실측 복사 | 16.7 / 9.1 | 65.6 / 65.8 |
| TFLOPS 비례 | 45.6 / 58.4 | 269.4 / 268.0 |
| 대역폭 비례 | 33.1 / 27.3 | 40.8 / 45.4 |
| (참고) 트리 모델 LOGO (76, v1 기준) | 12.9 | 48.3 |
| 절제: 대역폭 항 제거 | 15.4 / 12.4 | 28.3 / 21.3 |
| 절제: 오버헤드 항 제거 | 23.7 / 22.6 | 88.9 / 93.8 |

1050에 맞춘 식이 배운 가중은 물리적으로 말이 된다: 오버헤드 비중 소형 0.80·대형 0.30, 연산 비중 산술강도 14 미만 0.27·15 초과 0.88. **트리가 끝내 못 한 "사양 → 속도" 전이를 파라미터 4개가 한다** — 특히 1050처럼 범위 밖(가장 느림)도 30%로 외삽한다(트리 48%, 복사 66%).

추론은 약하다: 1050→3060 19.9%(복사 18.7%와 비슷), 3060→1050 39.5%. 추론은 테스트셋 10배치뿐이라 오버헤드·호스트 변동이 지배하고 대역폭 효과가 흐리다.

## 4. 정직한 한계

- GPU 3대, 공통 54구성, 원본 GPU 하나로 맞추고 하나로 검증 — 표본이 작다. 방향은 뚜렷하지만 수치는 잠정.
- 호스트가 모두 다르다. 호스트비를 클럭비로 넣어도 되는 건 이번 세 CPU에서 확인했을 뿐이다. **CPU 백엔드 실측 비(4.33·2.46)로 넣으면 실패**한다(46.6/73.6) — 멀티코어 처리량이 아니라 싱글 스레드 디스패치가 병목이라서다.
- 대역폭 항은 1050→3060에선 도움(15.4→11.8), 반대 방향에선 중립(28.3 vs 29.5). 대역폭 스펙과 L2 캐시(4060 Ti 32 MB vs 3060 3 MB) 차이가 섞여 있어 분리 못 했다.
- 산술 강도는 배치 1 정적 프록시라 실제 값이 아니다. 순위로만 썼다.
- 기준 GPU에서 **그 구성을 잰 값이 필요**하다. 미지 구성 × 미지 GPU는 기존 모델(구조→기준 GPU 시간) + 이 식(기준 GPU → 새 GPU)을 이어 붙여야 한다(미실행).

## 5. 논문에 주는 것

- **camera-ready(10/7):** 기여 2(메모리 쓰기 프록시)의 **해석 근거가 처음 생겼다.** 지금 원고의 Roofline 문단은 "정적 프록시라 인과는 증명 못 한다"로 방어만 하고 있는데, 3060(대역폭 우위)·4060 Ti(연산 우위) 비교에서 저강도 구성은 대역폭 비를, 고강도 구성은 TFLOPS 비를 따른다는 실측이 생겼다. §4.3에 한 문장 + ResNet 폭별 한 줄이면 된다. Limitations의 "기술자 = 정체성" 문장 뒤에 "그러나 공개 사양으로 만든 오버헤드·메모리·연산 3항 식은 다른 GPU로 학습시간을 12~31% 오차로 전이한다"를 붙일 수 있다. 반영 여부는 교수님 결정.
- **다음 논문의 핵심:** 76에서 방향만 있던 "구조는 트리, 하드웨어는 매끄러운 함수"가 구체적인 식으로 생겼다. 구조 모델이 구성마다 (기준 시간, 오버헤드 비중, 연산/메모리 비중)을 내고, 하드웨어는 (호스트 싱글스레드, TFLOPS, 대역폭) 세 사양으로 스케일한다. 2080(대역폭 448 GB/s·TFLOPS 10, 4060 Ti와 같은 호스트)을 재면 대역폭 항을 L2 캐시와 분리할 수 있다 — 2080은 대역폭은 4060 Ti보다 높고 L2는 4 MB라 캐시 효과와 반대 방향을 가리킨다.
