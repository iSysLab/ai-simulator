# Leave-one-GPU-out — CUDA 기기 3대로 사양 전이를 시험 (2026-09-26)

스크립트 `eval_logo_gpu.py`, 수치 `paper/logo_gpu.json`. 브랜치 `ensemble`.

## 설정

- CUDA 기기 3대: GTX 1050(2.51 TFLOPS, 2 GB, 호스트 i3-8100) · RTX 3060(15.48, 12 GB, i7-10700F) · RTX 4060 Ti(26.98, 8 GB, 7800X3D; 632셀의 v1 3월 데이터).
- 학습: 632셀(4백엔드) + 외부 측정 전부(1050·3060 GPU, i3·i7 CPU) = 824셀, 기술자는 `env_*.json` 실제값. 타깃 log(y), 구성 단위 GroupKFold 4-겹 튜닝.
- 평가: GPU 하나를 통째로 빼고 학습 → 그 GPU 예측. 기준선 (a) 남은 GPU 중 TFLOPS 최근접 기기 실측 복사, (b) **구성별로 남은 두 GPU 실측을 log(TFLOPS)에 대해 직선 보간·외삽**(학습 없음). 민감도: 뺀 GPU의 사양을 최근접 기기 값으로 바꿨을 때 예측 배율.

## 읽기

1. **트리 모델은 여전히 사양을 쓰지 않는다.** 3060을 뺐을 때 모델이 거의 완벽(0.99)해 보이지만, 3060의 하드웨어 30열을 **전부** 4060 Ti 값으로 바꿔도 예측은 5%만 변한다(×0.95; 움직인 건 `cpu_freq_base_ghz` 하나, ×0.93). 즉 모델이 3060을 맞힌 건 사양 때문이 아니라, 학습에 들어온 1050(느림)과 4060 Ti(빠름)가 같은 "CUDA 잎"에 섞여 예측이 그 중간으로 끌려간 결과다 — 3060이 우연히 그 중간이었다. 1050 하나만 있던 때의 "4백엔드 평균이 우연히 맞았다"와 같은 현상이다.
2. **트리는 외삽을 못 한다.** 4060 Ti(가장 빠름)를 빼면 학습 1.75배·추론 2.38배 과대, 1050(가장 느림)을 빼면 추론 0.35배. TFLOPS 범위 밖은 가장 가까운 잎 값을 그대로 쓰기 때문.
3. **학습 없는 물리 기준선이 학습시간을 셋 다 이긴다.** 구성마다 "남은 GPU 두 대의 실측을 log(TFLOPS)에 대해 직선으로 잇는 것"만으로 학습시간 MAPE 22.8 / 7.0 / 9.2 — 모델(48.3 / 12.9 / 120.3)보다 낫고 외삽도 된다. 학습시간은 계산량이 지배해 TFLOPS에 매끄럽게 반응한다.
4. **추론은 TFLOPS 보간도 안 된다.** 추론(특히 소형)은 커널 실행 오버헤드 체제라 TFLOPS와 거의 무관하다 — 3060 추론은 보간이 1.41배 과대, 1050 추론은 모든 방법이 실패. 호스트 CPU(i3 vs i7 vs 7800X3D)가 섞여 있는 것도 원인이다.

## 결론과 의미

- **R1-5에 대한 답이 3대로도 바뀌지 않는다:** 기술자가 연속 축(값 3개)이 되어도 트리 앙상블은 그것을 전이 가능한 변수로 쓰지 않는다. 트리 구조 자체의 한계(분기 = 계단 함수, 외삽 불가)다.
- **후속 논문의 방향이 생겼다:** 학습시간에서는 "구성별 기준 기기 실측 × log(TFLOPS)의 매끄러운 함수"가 트리보다 낫다. 즉 하드웨어 전이는 트리에 기술자를 던져 넣는 방식이 아니라 **구조는 트리(또는 기존 모델)로, 하드웨어 스케일링은 단조·매끄러운 함수(log-linear, 단조 제약 GBM, 또는 roofline형 식)로 분리**하는 설계로 가야 한다. 추론 소형 구간은 별도로 오버헤드 항(호스트 CPU 포함)이 필요하다.
- camera-ready에는 Limitations 한 문장이면 충분하다: "CUDA 기기 3대로 기기 제외 검증을 해도 트리 모델은 TFLOPS·코어 수를 쓰지 않았고 범위 밖 기기를 외삽하지 못했다. 학습시간은 구성별 log-TFLOPS 보간이 더 정확했다(MAPE 7~23%)."

## 주의

- 세 GPU의 호스트가 모두 다르고, 4060 Ti는 v1(3월)·1050·3060은 v2(9월) 데이터다. 데스크톱 드리프트(소형 +20%)가 4060 Ti 외삽 결과에 섞여 있다. 2080을 4060 Ti와 같은 호스트(7800X3D)에서 v2로 재면 이 교란이 사라지고, VRAM 8 GB가 같아 VRAM 분기로도 못 가르므로 가장 깨끗한 시험이 된다.
- 기기당 평가 셀 54~158개, 시드 1개. 방향성은 뚜렷하지만 수치는 잠정.
